# EduJournal — шкільний електронний журнал

Вебсистема обліку та управління навчальним процесом закладу загальної середньої освіти.
Навчальний проєкт з дисципліни «Веб-орієнтовані бази даних» і тема дипломної роботи.

**Автор:** Крайнов Дмитро, група 21мКН

## Можливості

- ролі: адміністратор, вчитель, учень, батьки (права перевіряються на сервері);
- вчитель виставляє оцінки й задає ДЗ лише з предметів, які викладає;
- учень і батьки бачать лише власні дані / дані своїх дітей;
- учні, вчителі, класи, предмети, розклад;
- журнал оцінок (1–12) і відвідуваності;
- домашні завдання зі здачею робіт учнями та оцінюванням;
- звіти: рейтинг учнів, середній бал класів, успішність з предмета, незадовільні оцінки, відвідуваність; експорт CSV;
- прив'язка батьків до дітей.

## Технології

React 19, Vite, React Router, Axios, Recharts · Node.js, Express 5, JWT, bcrypt, express-validator, multer · PostgreSQL

## Запуск

Потрібні Node.js 22+ і PostgreSQL.

```bash
cd backend
cp .env.example .env      # вказати свої параметри БД і JWT_SECRET
npm install
npm run db                # створення структури БД
npm run seed              # (необов'язково) демо-дані, очищає базу; пароль усіх акаунтів: password123
npm run dev               # API: http://localhost:5000

cd ../frontend
npm install
npm run dev               # http://localhost:5173
```

Структура бази даних: `backend/database/schema.sql`.

## Облікові записи

Самостійна реєстрація доступна лише учням і батькам. Після реєстрації адміністратор
додає учня до класу (розділ «Учні») або прив'язує батьків до дитини (розділ «Батьки»).
Вчителів і адміністраторів створює адміністратор.

Демо-акаунти після `npm run seed` (пароль `password123`):

| Батьки | parent1@school.com |

